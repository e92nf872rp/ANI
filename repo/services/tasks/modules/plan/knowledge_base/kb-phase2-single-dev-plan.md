## 1. 阶段一：OCR 服务模块（API 调用版）

**目标**：扫描 PDF、图片型 PDF、常见图片（png/jpg）经外部 OCR 接口识别，任务提交→状态查询→结果获取→入库全链路通。

| #   | 任务                  | 内容                                                                                                                                | 工期    |
| --- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ----- |
| 1.1 | OCR 契约定义            | Services v1.yaml 新增 `POST /ocr/tasks`、`GET /ocr/tasks/{task_id}`、`GET /ocr/tasks/{task_id}/result` 三端点 + schema + 幂等键；SDK 生成与门禁校验 | 0.5 天 |
| 1.2 | OCR 客户端适配           | rag-engine `app/clients/ocr_api.py` 对接外部 OCR 接口（鉴权/超时/重试/错误码映射），配置进环境变量                                                           | 1 天   |
| 1.3 | OCR 任务异步链路          | outbox + NATS consumer + AsyncTask 状态机（复用 kb-service 既有模式），提交→running→completed/failed                                            | 2 天   |
| 1.4 | 扫描件判定与 OCR fallback | parse\_service 检测文本层为空的 PDF → 触发 OCR（当前代码标注 OCR deferred，需实装）；图片文档直接走 OCR                                                         | 2 天   |
| 1.5 | OCR 结果结构化入库         | OCR regions → 节点/chunk 转换，与切分/索引/检索链路打通                                                                                           | 2 天   |
| 1.6 | 失败重试与异常提示           | 接口失败分类（超时/限流/格式不支持）、任务重试入口、部分页成功语义                                                                                                | 1 天   |
| 1.7 | 测试与批次闭环             | 单测 + e2e + development record                                                                                                     | 1 天   |

**小计 9.5 人天**&#x20;
